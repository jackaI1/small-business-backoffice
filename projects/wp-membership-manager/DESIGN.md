# Admin interface

The plugin extends the WordPress admin interface. The host provides typography, colours, focus rings, navigation and buttons. The screen uses the native `wrap`, `widefat striped`, `notice` and `submit_button` patterns rather than a separate application shell.

Reports come first, forms follow, and the underlying record tables remain visible for checking changes. Forms use labelled native controls inside disclosure sections. Tables scroll horizontally within their containers on narrow screens. Form inputs are limited to the available width. Errors and successful changes appear as text notices with a status role.

There is no animation, decorative imagery, custom font or independent colour theme. WordPress admin styles remain the visual authority.
