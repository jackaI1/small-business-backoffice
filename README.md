# Small business back office

I wanted to learn how a company's back office works, so I built small tools for a practice company using fictional data. They cover accounts, approvals, people, claims and campaigns.

Each tool lives in its own folder under `projects/`, with its own instructions, examples, checks and limitations. These are separate learning projects. They are not a production business system, and the fictional records do not describe real customers or employees.
